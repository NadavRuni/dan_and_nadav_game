# Frontend Application (`frontend`)

## Purpose

This directory contains the client-side application that users interact with. It is a simple, static web application built with HTML and vanilla JavaScript.

## File Map

- **index.html**: The main entry point of the application. It contains the UI for uploading an image.
- **confirm_rectangle.html**: The page where the user can view and approve the automatically detected table boundary.
- **analysis.html**: The page for displaying the final analysis results.
- **nav_watcher.js**: A JavaScript file that likely handles the logic for polling the backend and navigating the user between the different steps of the process.
