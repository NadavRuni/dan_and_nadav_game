# Game State Models (`game_class`)

## Purpose

This directory defines the core data structures for the application. It contains Python classes that represent the different elements of the pool game, providing a structured way to manage the data throughout the analysis pipeline.

## File Map

This directory contains many classes, each representing a concept in the game. Key examples include:
- **C_ball.py**: Defines the `Ball` object, with attributes for position, radius, and color type.
- **C_table.py**: Defines the `Table` object, representing the entire playing surface.
- **C_pocket.py**: Defines the `Pocket` object.
- **C_line.py**: Represents geometric lines for shot calculation.
- **C_bestShot.py**: A class for calculating and representing potential shots.
